# GenZDoc — Free Online PDF & Image Tools

[![Live Website](https://img.shields.io/badge/Website-genzdoc.com-blue?style=for-the-badge&logo=google-chrome)](https://genzdoc.com)
[![Privacy](https://img.shields.io/badge/Privacy-Client--Side-green?style=for-the-badge)](https://genzdoc.com)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg?style=for-the-badge)](LICENSE)

[**GenZDoc**](https://genzdoc.com) is a fast, free, and privacy-focused suite of browser-based utilities designed for PDF document management and image manipulation without paywalls, subscriptions, or mandatory account creation.

---

## 🛠️ Featured Tools & Direct Links

### 📄 PDF Utilities
- **[PDF Compressor Online](https://genzdoc.com/tools/pdf-compressor):** Reduce PDF file sizes directly in your browser. Re-encode and inspect output size before downloading.
- **[JPG to PDF Converter](https://genzdoc.com/tools/jpg-to-pdf):** Convert and combine multiple JPG/PNG images into a clean single PDF file.
- **[Merge PDF Files](https://genzdoc.com/tools/pdf-merge):** Combine multiple PDF documents into one organized document.
- **[Split PDF Pages](https://genzdoc.com/tools/pdf-split):** Extract individual pages or separate custom page ranges.
- **[Word to PDF](https://genzdoc.com/tools/word-to-pdf):** Convert Word (.docx) files to standard PDF format instantly.
- **[PDF to Word](https://genzdoc.com/tools/pdf-to-word):** Convert PDF documents into editable Word documents.
- **[Sign PDF Online](https://genzdoc.com/tools/sign-pdf):** Add digital or drawn signatures to contracts and agreements securely.

### 🖼️ Image Utilities
- **[Free Image Compressor](https://genzdoc.com/tools/image-compressor):** Re-encode JPEG, PNG, and WebP images client-side. Adjust quality settings and compare file sizes before downloading.
- **[Online Photo Editor](https://genzdoc.com/tools/image/photo-editor):** Advanced photo editing with precision crop, geometric shapes, aspect-ratio presets, and filters.
- **[Image to JPG Converter](https://genzdoc.com/tools/image/convert-to-jpg):** Convert PNG, WebP, HEIC, and GIF files to standard JPG format.
- **[Resize Image](https://genzdoc.com/tools/image/resize-image):** Scale image dimensions to exact pixel dimensions.
- **[Crop Image](https://genzdoc.com/tools/image/crop-image):** Custom cropping with aspect ratio presets.

---

## 🔒 Privacy & Security First
Unlike traditional PDF web services that upload sensitive documents to unverified cloud servers, GenZDoc processes tasks directly in the user's web browser using modern Web APIs (HTML5 Canvas API, WebAssembly, and client-side processing). Your sensitive personal files and financial documents never leave your machine.
